# Finpulse 💰

**Finpulse** is a modern, lightweight, and 100% offline personal finance tracker application built natively for Android. It helps users manage daily income, expenses, and monthly or yearly financial reports with maximum data privacy.

---

## Key Features ✨

* **Income & Expense Tracking:** Effortlessly log your daily financial transactions.
* **Monthly & Yearly Reports:** Get a clear visual breakdown of your financial stats.
* **Multi-Currency Support:** Supports global currencies including BDT (টাকা), USD (ডলার), EUR (ইউরো), SAR (রিয়াল), MYR (রিঙ্গিত), and GBP (পাউন্ড).
* **100% Offline & Private:** No internet connection required. All financial data stays strictly on your local device.
* **Backup & Restore:** Easily export your entire database into a `.json` file and import it anytime to restore your data.

---

## Tech Stack 🛠️

* **Language:** Kotlin (100% Native)
* **IDE:** Android Studio
* **Data Format for Backup:** JSON (`.json`)

## Installation & Setup 🚀

Follow these steps to run the project locally on your machine:

1. Clone the repository:
   ```bash
   git clone [https://github.com/zr-rieaz/FinPulse.git](https://github.com/zr-rieaz/FinPulse.git)```
2.  Open Android Studio.
3. Click on Open an Existing Project and select the cloned FinPulse folder.
4. Wait for the Gradle Sync to complete.
5. Connect your Android Device or Emulator and click the Run button.
